# Hugg TumGard Product Page Replica

A replica of the Hugg TumGard product page, recreating its layout, visual design, product imagery, and interactive elements.

**Live Website:** https://hugg-replica.vercel.app/

**Original Website:** http://gethugg.com/buy-tumgard/

**GitHub Repository:** https://github.com/vedantchaubey/hugg-replica

## Overview

This project recreates the Hugg TumGard product page using HTML, CSS, JavaScript, and supporting website assets. The focus is on reproducing the original page's appearance, responsive layout, and scrolling experience.

## Features

- Product page layout and imagery
- Responsive desktop and mobile presentation
- Problem-to-solution illustration section
- Animated language ticker
- Sticky promotional offer bar
- “See the Science” button and associated interaction
- Supporting stylesheets, images, and website assets

## Tech Stack

- **HTML5** for page structure
- **CSS3** for styling and responsive layouts
- **JavaScript** for interactive behavior

## Project Structure

```text
hugg-replica/
├── index.html
├── README.md
├── vendor/
├── wp-content/
└── wp-includes/
```

- `index.html` is the main entry point.
- `vendor/` contains supporting resources.
- `wp-content/` contains website assets and related resources.
- `wp-includes/` contains supporting stylesheets and resources.

## Prerequisites

Choose one of the following ways to run the project:

- Python 3
- Visual Studio Code with the Live Server extension

No package installation or build step is required for the static website.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/vedantchaubey/hugg-replica.git
```

### 2. Open the project directory

```bash
cd hugg-replica
```

### 3. Start a local web server

Using Python:

```bash
python -m http.server 8000
```

On Windows, you can also run:

```powershell
py -m http.server 8000
```

Run the command from the directory containing `index.html`.

### 4. Open the website

Visit the following address in your browser:

http://localhost:8000

To stop the server, press `Ctrl + C` in the terminal.

## Alternative: Run with VS Code Live Server

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. View the website in your browser.

## Verification

After starting the website, check that:

- Images and stylesheets load correctly.
- The layout works at desktop and mobile screen sizes.
- The language ticker behaves as expected.
- The promotional offer bar behaves correctly while scrolling.
- The “See the Science” button works as intended.

The replica covers the product page through the “bohot kuch try kiya hain, lekin…” section, including the problem-to-solution illustrations and the “See the Science” button.
